# ZTG Heavy Parts - POS & Inventory System

This is the repository for the **ZTG Heavy Parts** Point of Sale (POS) and Inventory Management System. The project is split into two parts: a **Laravel backend** (API) and a **React/Vite frontend** (UI).

Follow the instructions below to set up and run this project on a new device.

---

## 🛠️ Prerequisites

Before you begin, ensure you have the following installed on your machine:
* **PHP** (v8.1 or higher)
* **Composer** (for PHP dependencies)
* **Node.js & npm** (for Frontend dependencies)
* **MySQL** (or XAMPP/WAMP for local database hosting)
* **Git**

---

## 🚀 Installation & Setup Guide

### 1. Clone the Repository
Open your terminal and clone the repository to your local machine (e.g., inside your `htdocs` folder if using XAMPP):
```bash
git clone <your-repository-url>
cd ztg-heavyparts
```

### 2. Backend Setup (Laravel API)
The backend handles the database, business logic, and API endpoints.

1. Open a terminal and navigate to the backend folder:
   ```bash
   cd backend
   ```
2. Install PHP dependencies:
   ```bash
   composer install
   ```
3. Set up your environment file:
   * Copy the example `.env` file:
     ```bash
     cp .env.example .env
     ```
   * Open the `.env` file and update your database credentials. (If you are using XAMPP, it usually looks like this):
     ```env
     DB_CONNECTION=mysql
     DB_HOST=127.0.0.1
     DB_PORT=3306
     DB_DATABASE=ztg_heavyparts   # Make sure to create this database in phpMyAdmin first!
     DB_USERNAME=root
     DB_PASSWORD=
     ```
4. Generate the application key:
   ```bash
   php artisan key:generate
   ```
5. Run database migrations and seeders (this sets up the tables and creates the default admin user):
   ```bash
   php artisan migrate --seed
   ```
6. Start the backend server:
   ```bash
   php artisan serve
   ```
   *The backend API will now be running at `http://127.0.0.1:8000`*

---

### 3. Frontend Setup (React + Vite)
The frontend contains the user interface and interacts with the Laravel API.

1. Open a **new** terminal window and navigate to the frontend folder:
   ```bash
   cd frontend
   ```
2. Install Node dependencies:
   ```bash
   npm install
   ```
3. Set up the frontend environment (if necessary):
   * If there is a `.env.example` file in the frontend folder, copy it to `.env`:
     ```bash
     cp .env.example .env
     ```
   * Ensure it points to your local Laravel API (usually `http://127.0.0.1:8000/api`).
4. Start the frontend development server:
   ```bash
   npm run dev
   ```
   *The frontend UI will now be accessible in your browser (usually at `http://localhost:5173` or `http://localhost:3000`).*

## 🔑 Default Login Credentials
After migrating and seeding the database, you can log into the system using the default admin account:

* **Username/Email:** `admin@ztg.com` (or the username generated by your `AdminUserSeeder`)
* **Password:** `admin123` (or password)

*(Check your `backend/database/seeders/AdminUserSeeder.php` if the credentials differ).*

## 📌 Development Notes
* **UI/UX Source of Truth:** All design implementations strictly follow the visual reference files stored in the `ZTG-main` directory.
* **Layouts:** The frontend utilizes explicit CSS calculations (`calc(100vh / 0.9)`) on outer wrappers to perfectly fit the viewport and compensate for the `zoom: 0.9` body scaling. 
* **Routing:** Protected routes use role-based access control (Admin, Cashier, Supervisor, Checker).
